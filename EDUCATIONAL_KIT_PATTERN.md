# Educational Kit Pattern

This document defines how to convert AI experiments, workflows, and lessons into reusable educational kits inside the wider `lippytm` ecosystem.

## Purpose
Make AI development easier to teach and repeat by packaging strong patterns into modular kits.

## Core Kit Pattern
1. Start with a working lesson, experiment, or workflow
2. Identify the smallest reusable unit
3. Write a short explanation of the purpose
4. List inputs, outputs, and dependencies
5. Add a walkthrough or example
6. Add reflection notes or lessons learned
7. Package the result as a reusable kit, template, or starter system

## Kit Types

### 1. Lesson Kit
Use for:
- repo-based lessons
- setup guides
- learning exercises
- walkthroughs

### 2. Workflow Kit
Use for:
- agent flows
- routing patterns
- evaluation loops
- documentation routines

### 3. Builder Kit
Use for:
- coding practice packs
- debugging checklists
- repo structure templates
- mixed-environment setup guides

### 4. Reflection Kit
Use for:
- self-improvement checklists
- review loops
- lessons learned logs
- architecture review prompts

## Best Practices
- keep each kit modular
- explain what problem it solves
- keep examples small enough to reuse
- separate experimental notes from polished kit instructions
- link kits back to the teaching and learning repos
