**Role:** manufacture bounded agent and swarm blueprints, tests, artifacts, and evidence

## Factory output

Factory.ai may generate configuration, code scaffolds, tests, documentation, work packets, media plans, and business-experiment plans. It does not automatically deploy, publish, charge customers, transfer money, mint NFTs, or certify a product.

## Swarm Blueprint contract

Every manufactured swarm requires:

- swarm ID and version;
- one bounded purpose;
- human owner;
- coordinator;
- agent roster and role descriptions;
- model-line namespace;
- permitted data classes;
- tool and repository scopes;
- connector scopes;
- budget and timeout;
- input and output schemas;
- acceptance criteria;
- required tests and gates;
- stop-work and quarantine conditions;
- monitoring, correction, rollback, revocation, retirement, and succession plans;
- HumanApprovalGate status.

## Manufacturing lifecycle

`request → validate → classify → select blueprint → generate sandbox artifacts → create tests → run static and unit checks → red-team → assemble Quality Evidence Packet → human review → approve bounded pilot or reject → monitor → correct or retire`

## Ethical Revenue Machine contract

A manufactured revenue experiment requires:

- customer or learner problem;
- approved product version;
- target audience;
- value hypothesis;
- price hypothesis;
- cost ceiling;
- delivery channel;
- support and refund plan;
- disclosures and prohibited claims;
- success, pause, and stop criteria;
- revenue, cost, margin, conversion, learner outcome, complaint, refund, and correction metrics;
- identified human approver.

## Financial authority boundary

Factory-generated agents have no authority to:

- open financial or merchant accounts;
- accept legal terms;
- charge customers;
- transfer or invest funds;
- borrow;
- sign contracts;
- file taxes;
- create wallets or handle seed phrases;
- promise earnings, funding, investment returns, employment, or business success.
