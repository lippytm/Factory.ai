# Content and Product Variant Model

This document defines how reusable systems can branch into multiple content and product variants inside the wider `lippytm` ecosystem.

## Purpose
Support flexible reuse so one strong base can lead to many content, lesson, membership, affiliate, and product variants without losing structure.

## Core Principle
A strong base should support many outputs while keeping shared setup, support, review, and security patterns stable.

## Variant Types

### 1. Content Variants
Use for:
- short-form educational content
- long-form lesson packs
- public demo content
- audience-specific content versions

### 2. Product Variants
Use for:
- starter kits
- premium bundles
- support add-ons
- implementation packs

### 3. Membership Variants
Use for:
- entry-level tiers
- advanced tiers
- specialist learning tracks
- recurring update programs

### 4. Affiliate Variants
Use for:
- partner content packs
- campaign support packs
- audience-specific promotion versions
- derivative landing systems

## Best Practices
- keep the base reusable and documented
- explain what changes between variants
- keep support notes with each major variant
- include review and security reminders in every reusable version
- promote strong variants back into templates when they prove durable
